# IM-extractTools
A colection of scripts to extract files from the PS2 game "Ichigo Mashimaro"



# Text Flags

Those are as follows:
- B Ligth blue
- C Clears what came before (WHAT!? WHY DO YOU NEED THAT!?)
- D Makes the text big (でかい)
- E Nothing
- F Makes the text appear into screen slowly
- G Green
- I idk, nothing seemingly but it doesn't appear
- J Also makes the text big
- K A strnage map to the game's bitmap
- O Orange
- P Dark blue
- Q Shakes the screen (Quiver?)
- R Red
- S Take some time to appear (Slow?)
- T idk, nothing seemingly but it doesn't appear
- W Stops effect

# K Flag

This one maps 2 bytes to a certain glyph in the font. It is as follows:

- 0407 -> A
- 0408 -> B
- 0409 -> C
- 040a -> D
- 040b -> E
- 040c -> F
- 040d -> G
- 040e -> H
- 040f -> I
- 0410 -> J
- 0411 -> K
- 0412 -> L
- 0413 -> M
- 0414 -> N
- 0415 -> O
- 0416 -> P
- 0417 -> Q
- 0418 -> R
- 0419 -> S
- 041a -> T
- 041b -> U
- 041c -> V
- 041d -> W
- 041e -> X
- 041f -> Y
- 0420 -> Z
